# ArcForge 0.4.0

ArcForge 0.4.0 adds production-grade Git and repository-workflow reasoning while preserving the four shared operating modes introduced in 0.3.2.

## Added

- `git-workflows`, the fifteenth portable Agent Skill, for branch topology, merges and rebases, worktrees, distributed ref updates, hosted protections, tags, semantic versions, release provenance, shared-history migration, secret incidents, and recovery.
- Canonical paper 147, **Production-Grade Git and Git Flow**, its portable reference, worked example, user guide, catalog route, and source map.
- Behavioral pressure cases covering unsafe force pushes, ambiguous push outcomes, stale CI, exposed signing keys, immutable published tags, and release-exception pressure.

## Changed

- `quality-release` now distinguishes executed, planned, claimed, unavailable, and contradicted evidence; binds proof to the exact release subject; closes cross-skill boundaries; and prevents a waiver from hiding a critical blocker.
- README, skill guides, runtime metadata, catalog/install groups, corpus metadata, checksums, and manifests now cover 15 skills and 147 papers.

## Compatibility

- Existing technical skill IDs remain unchanged.
- Skills remain portable across Claude Code, Codex, and compatible Agent Skills runtimes.
- `git-workflows` is additive; existing installations can install it independently or refresh the full repository.

See [CHANGELOG.md](../../CHANGELOG.md) for the complete release history.
